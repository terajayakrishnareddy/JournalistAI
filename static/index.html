System & Engine Configuration

JournalistAI operates a hybrid local-and-cloud architecture designed specifically for privacy-sensitive newsrooms.

  • • Transcription Engine: faster-whisper (tiny / medium / large-v3) running 100% locally on CPU multi-threading.
  • • Fact-Checking Engine: Google Gemini 2.5 Pro via AI Studio API for entity quotation extraction and claim verification steps.
  • • Database Storage: Local SQLite with transactional ACID persistence.
